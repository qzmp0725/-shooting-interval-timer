아이폰 설치 방법

이 폴더는 PWA(홈 화면 웹앱)입니다. iPhone에서 제대로 설치하려면 HTTPS 주소에서 열어야 합니다.

1. 이 폴더 전체를 정적 웹호스팅(예: GitHub Pages/Netlify 등)에 올립니다.
2. iPhone Safari에서 그 HTTPS 주소를 엽니다.
3. 공유 버튼 → '홈 화면에 추가'를 누릅니다.
4. 홈 화면의 Shooting Timer 아이콘으로 실행합니다.
5. 처음 한 번 Start 버튼을 눌러 오디오 재생 권한을 줍니다.

타이머 규칙
- 01:00 Start
- 02:00 Unload
- 02:55 Attention
- 03:00 Start
- 이후 같은 사이클 반복
- 60:00 Stop 후 종료

중요
- 음성은 1시간짜리 오디오 트랙에 미리 정확한 시점으로 삽입되어 있어, 단순 JavaScript 타이머보다 iPhone에서 안정적으로 재생됩니다.
- 홈 화면 앱으로 실행한 뒤 미디어 볼륨을 확인하세요.
